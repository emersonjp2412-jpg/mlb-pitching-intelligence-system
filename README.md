# ⚾ MLB Pitching Intelligence System

End-to-end MLB pitching intelligence system combining biomechanics, Statcast data, clustering, and machine learning to model pitcher velocity and performance efficiency.

---

## 🧠 Project Overview

This project analyzes MLB pitchers using Statcast data and machine learning workflows inspired by MLB R&D departments.

The system combines:
- Biomechanics-inspired feature engineering
- Pitcher clustering
- Velocity prediction modeling
- Scouting-style evaluation metrics
